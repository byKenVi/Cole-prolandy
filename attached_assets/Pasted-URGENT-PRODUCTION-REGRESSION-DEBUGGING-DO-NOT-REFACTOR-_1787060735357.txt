Specifically verify:

1. Endpoint is /wix-data/v2/items/query
   NOT /wix-data/v2/items

2. HTTP method is POST.

3. Content-Type is application/json.

4. wix-site-id header exists and is exactly sourced from WIX_SITE_ID.

5. Authorization header uses exactly the configured
   WIX_API_AUTHORIZATION value.

   DO NOT automatically prepend "Bearer " unless that is what the configured
   working credential actually requires.

6. dataCollectionId resolves exactly to:
   AllContractors

   "paging": {
     "limit": 50,
     "offset": 0
   }

   Do not use "skip".

   the cause rather than breaking full sync.
