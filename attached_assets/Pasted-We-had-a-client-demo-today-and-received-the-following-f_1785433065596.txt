## Goal
Resolve all reported bugs, improve the user experience, and ensure the application is production-ready.

### 1. Delete Lead confirmation bug
Current behavior:
- When deleting a lead, the confirmation/error message appears next to the Delete button instead of inside the confirmation modal.

Expected behavior:
- The confirmation dialog should behave correctly.
- Success and error messages must appear inside the modal (or as a proper toast if that is the application's design system), never beside the button.
- Verify the entire delete flow works correctly.

---

### 2. Contractor wallet top-up flow
Current behavior:
- When a contractor has insufficient balance and tries to purchase a lead, clicking "Add Funds" does not continue the flow.
- The user has to manually navigate to the Wallet page.

Expected behavior:
- When balance is insufficient, display an inline "Add Funds" flow directly from the purchase screen.
- After a successful payment/top-up, automatically refresh the balance.
- Continue the original purchase flow without forcing the user to manually visit the Wallet page.
- The experience should be seamless.

---
