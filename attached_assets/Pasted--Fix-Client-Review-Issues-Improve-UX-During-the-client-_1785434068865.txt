# Fix Client Review Issues & Improve UX

During the client demo, several UX and functional issues were identified. Please fix all of them and perform a complete quality review to ensure similar issues do not exist elsewhere in the application.

## 1. Delete Lead Confirmation

### Current issue

When deleting a lead, the success/error message appears outside the confirmation modal, near the delete button.

### Expected behavior

* The confirmation dialog should behave correctly.
* Success and error messages should appear inside the modal or as a global toast notification.
* The modal should close only after a successful deletion (or follow the existing UX pattern consistently).
* Refresh the lead list automatically after deletion.
* Ensure no UI glitches occur.

---

## 2. Contractor Wallet Top-up Flow

### Current issue

When a contractor tries to purchase a lead without sufficient balance, clicking **Add Funds** does not allow them to continue the purchase seamlessly.

The user must manually navigate back to the Wallet page.

### Expected behavior

Create a frictionless flow.

Example:

1. Contractor selects a lead.
2. System detects insufficient balance.
3. Show an "Insufficient Balance" dialog.
4. Clicking **Add Funds** opens the funding flow immediately.
5. After successful payment:

   * update the wallet balance,
   * automatically return to the previous purchase flow,
   * allow the contractor to complete the purchase without restarting the process.

The user should never have to manually navigate back to continue.
